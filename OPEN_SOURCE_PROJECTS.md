## 🎯 Step-by-Step: Your First Contribution

### Let's contribute to Pandas (Add merge() examples)

#### Step 1: Fork & Clone (5 minutes)
```bash
# 1. Go to https://github.com/pandas-dev/pandas
# 2. Click "Fork" button
# 3. Clone your fork
git clone https://github.com/Akrati36/pandas.git
cd pandas

# 4. Add upstream remote
git remote add upstream https://github.com/pandas-dev/pandas.git

# 5. Verify remotes
git remote -v
```

#### Step 2: Setup Environment (10 minutes)
```bash
# Create virtual environment
python -m venv venv
source venv/bin/activate  # Windows: venv\Scripts\activate

# Install in development mode
pip install -e .

# Install development dependencies
pip install -r requirements-dev.txt

# Run tests to verify setup
pytest pandas/tests/test_merge.py
```

#### Step 3: Create Branch (1 minute)
```bash
# Create feature branch
git checkout -b add-merge-examples

# Verify branch
git branch
```

#### Step 4: Find the File (2 minutes)
```bash
# The file to edit
pandas/core/reshape/merge.py

# Or documentation file
doc/source/user_guide/merging.rst
```

#### Step 5: Add Examples (30 minutes)
```python
# Add to merge.py docstring

"""
Examples
--------
>>> df1 = pd.DataFrame({'key': ['A', 'B', 'C'],
...                      'value1': [1, 2, 3]})
>>> df2 = pd.DataFrame({'key': ['A', 'B', 'D'],
...                      'value2': [4, 5, 6]})

Inner merge (default):
>>> df1.merge(df2, on='key')
  key  value1  value2
0   A       1       4
1   B       2       5

Left merge (keep all rows from left):
>>> df1.merge(df2, on='key', how='left')
  key  value1  value2
0   A       1     4.0
1   B       2     5.0
2   C       3     NaN

Outer merge (keep all rows from both):
>>> df1.merge(df2, on='key', how='outer')
  key  value1  value2
0   A     1.0     4.0
1   B     2.0     5.0
2   C     3.0     NaN
3   D     NaN     6.0
"""
```

#### Step 6: Test Your Changes (5 minutes)
```bash
# Run specific tests
pytest pandas/tests/test_merge.py -v

# Run docstring tests
pytest --doctest-modules pandas/core/reshape/merge.py

# All tests should pass ✓
```

#### Step 7: Commit Changes (2 minutes)
```bash
# Stage changes
git add pandas/core/reshape/merge.py

# Commit with clear message
git commit -m "DOC: Add examples to DataFrame.merge() documentation

- Added examples for inner, left, and outer merge
- Showed expected output for each merge type
- Explained common use cases

Closes #55234"
```

#### Step 8: Push to Fork (1 minute)
```bash
# Push branch to your fork
git push origin add-merge-examples
```

#### Step 9: Create Pull Request (5 minutes)
```
1. Go to https://github.com/Akrati36/pandas
2. Click "Compare & pull request"
3. Fill in PR template:

Title: DOC: Add examples to DataFrame.merge() documentation

Description:
This PR adds comprehensive examples to the DataFrame.merge() 
documentation to help users understand different merge types.

Changes:
- Added examples for inner merge
- Added examples for left merge
- Added examples for outer merge
- Showed expected output for each type

Closes #55234

4. Click "Create pull request"
```

#### Step 10: Respond to Feedback (Ongoing)
```bash
# If maintainers request changes:

# 1. Make changes locally
# Edit files as requested

# 2. Commit changes
git add .
git commit -m "Address review feedback"

# 3. Push to same branch
git push origin add-merge-examples

# PR updates automatically!
```
